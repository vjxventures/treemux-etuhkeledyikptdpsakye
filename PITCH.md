# CodeMentor Live

**An AI-powered pair programming assistant that instantly analyzes code from text or screenshots, providing real-time suggestions, bug detection, and educational explanations to help developers write better code faster.**

CodeMentor Live solves the problem of developers needing instant, expert-level code review without waiting for human reviewers. Unlike traditional static analysis tools, it uses multi-modal AI to understand code from any source (pasted text or screenshots), provides streaming real-time feedback, and offers both actionable suggestions and educational explanations. It's like having a senior developer watching over your shoulder 24/7.

What makes it technically impressive: Full streaming AI responses with the Vercel AI SDK for instant feedback, multi-modal analysis supporting both text and image inputs, beautiful gradient UI with shadcn/ui components, and two distinct analysis modes (proactive suggestions vs. educational explanations). Built with Next.js 16, deployed on Vercel, and powered by Claude Sonnet 3.5 for state-of-the-art code understanding.

Perfect for developers learning new languages, teams doing code reviews, students debugging homework, or anyone wanting instant expert feedback on their code without context-switching to forums or documentation.
